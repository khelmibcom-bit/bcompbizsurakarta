## 📝 Catatan Penting

1. **Skill Global vs Project-Specific**
   - Global: `C:\Users\INTEL\.claude\skills\` - tersedia di semua project
   - Project-specific: `<project>/.claude/skills/` - hanya untuk project tertentu

2. **Auto-Discovery**
   - OpenCode/Claude Code otomatis menemukan skill dari folder skills
   - Tidak perlu registrasi manual

3. **Skill Dependencies**
   - Beberapa skill membutuhkan Python (seperti `claude-seo`)
   - Beberapa skill membutuhkan Playwright (seperti `browse`)

4. **Update Skill**
   ```powershell
   # Update skill dari GitHub
   cd "C:\Users\INTEL\.claude\skills\claude-seo"
   git pull origin main
   ```
